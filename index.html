Google Slides can't open a file straight from a website, so here's the quick way to get it in.

Downloaded: PalmettoYL-ClubNight.pptx
1
Click Open Google Drive below. It opens in a new tab.
2
Drag PalmettoYL-ClubNight.pptx out of your Downloads folder and drop it anywhere on the Drive window.
3
Double-click the file in Drive. It opens in Google Slides with every slide ready to present.
Already have a Slides deck open? Use File → Import slides → Upload and pick the same file. Presenting from PowerPoint or ProPresenter instead? The downloaded file works there as-is, no Drive needed.
